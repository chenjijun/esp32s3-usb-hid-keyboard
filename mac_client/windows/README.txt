ESP32 无线键盘 · Python 版客户端（Windows 使用说明）
====================================================

【这是什么】
ESP32-S3 板子插在被控主机的 USB 口上，本程序在你的 Windows 电脑上把按键发过去。
板子对主机来说就是一个普通 USB 键盘（外加鼠标和多媒体键），免驱。

【怎么开】
双击 ESP32Keyboard\ESP32Keyboard.exe。
不需要装 Python、不需要装依赖，打包时已经带在里面了。

【第一次连】
1. 板子插在「被控主机」上（就是你要操作的那台），上电。
2. 板子上按 BOOT 键选链路：
       BLE     ：灯蓝色（未连）→ 紫色（已连）
       Wi-Fi   ：灯绿色（未连）→ 黄色（已连）
3. 本程序里选同样的链路，点「连接」。
   蓝牙模式下，Windows 得有蓝牙适配器（设置 → 蓝牙和其他设备 里能看到）；
   Wi-Fi 模式下，先让本机连上板子开的热点 ESP32-Keyboard / 密码 esp32keyboard，
   主机填 192.168.4.1、端口 8266，再点「连接」。

【本机键盘转发】
点「开始捕获」，本机按键会被吞掉、全部转给主机；点「停止」或按 Ctrl+Alt+Esc 恢复
（停止键在任何情况下都有效，卡住了就按它）。
Windows 上不需要授权，但有两类按键系统不让抓，属于限制而不是 bug：
  · Ctrl+Alt+Delete（系统保留组合）
  · 以管理员身份运行的窗口里的按键 —— 想要也能抓，就右键本程序 →「以管理员身份运行」，
    这时反过来，普通窗口的按键一样抓得到。

【鼠标】
右侧「拖动这里移动指针」区域拖动 = 移动指针，速度滑杆 0.5×–4×。
左/中/右三键是按下发 down、松手发 up；要框选或拖文件，先点「按住左键」锁住，
再去拖拖拽区，完事点「松开左键」。

【BIOS】
「BIOS 启动键」里选 Del / F2 / F12 等，点一下写进板子（掉电保持），
之后每次上电板子自己连发，主机 POST 阶段就能收到。已经开机想再敲一次，用「立即连发」。

【卡住了】
点「释放全部按键」；断开连接或关窗口也会自动松键。

【已知限制】
· exe 没有代码签名，第一次运行 Windows 会提示「已保护你的电脑」，
  点「更多信息」→「仍要运行」。或者右键 exe → 属性 → 解除锁定。
· 界面按 1256×862 设计，建议屏幕 1920×1080 或更高；小屏笔记本上窗口会被挤。
· 界面需要 .NET 之前的自带组件都在系统里（Tk 已打包），不用另外装运行库。

【想改代码】
源码在同目录 ble_keyboard_client.py，装 Python 3.9+ 后：
    python -m pip install -r requirements.txt
    python ble_keyboard_client.py            # 直接运行
    python ble_keyboard_client.py --cli      # 命令行模式
重新打包用 build_win.bat（需要联网装 PyInstaller）。
